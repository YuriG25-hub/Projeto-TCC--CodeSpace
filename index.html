🚀 Bem-vindo ao CodeSpace!

Você é um piloto espacial que controla sua nave através de código de programação. Escreva comandos para navegar pelo espaço, desviar de meteoros e alcançar o objetivo!

🕹️ Comandos Básicos

frente(N) Move a nave para a direita N vezes
tras(N) Move a nave para a esquerda N vezes
subir(N) Move a nave para cima N vezes
descer(N) Move a nave para baixo N vezes

🔧 Funções Auxiliares

obterY() Retorna a altura atual da nave
obterX() Retorna a posição horizontal da nave
alinhado() Retorna true se a nave está na mesma altura do objetivo

Use a seta para ver exemplos com condicionais →

💻 Estruturas de Controle

Além dos comandos básicos, você pode usar condicionais e laços para criar algoritmos mais inteligentes!

📌 Exemplo com if/else

// Verifica se a nave está alinhada com o objetivo
if (alinhado()) {
    frente(5);
} else {
    subir(3);
    frente(5);
}

📌 Exemplo com for

// Repete um padrão de movimento 3 vezes
for (let i = 0; i < 3; i++) {
    frente(2);
    subir(1);
}

📌 Exemplo com while

// Sobe até estar alinhado com o objetivo
while (!alinhado()) {
    subir(1);
}
frente(8);
